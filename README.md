# Лаборатори 2 — k6 гүйцэтгэлийн хэмжилт

K6 ашиглан локал HTTP серверийн хариу өгөх хугацаа, хүсэлтийн хурд, алдааны хувийг хэмжив. Серверийн `/health` зам нь хариу өгөхөөс өмнө 100 мс хүлээнэ. Туршилтын виртуал хэрэглэгч бүр хариуны статус 200 эсэхийг шалгаад дараагийн хүсэлтээс өмнө нэг секунд хүлээнэ.

## Орчин ба ажиллуулах заавар

```text
k6.exe v2.4.0 (commit/dd9395906d, go1.26.11, windows/amd64)
```

Эхний терминалд локал серверийг ажиллуулна.

```powershell
node server.cjs
```

Хоёр дахь терминалд туршилт бүрийг тусад нь ажиллуулна.

```powershell
New-Item -ItemType Directory -Force results | Out-Null
k6 run --no-color --quiet --vus 5 --duration 1m load-test.js 2>&1 | Tee-Object results/run-05vu.txt
k6 run --no-color --quiet --vus 30 --duration 1m load-test.js 2>&1 | Tee-Object results/run-30vu.txt
k6 run --no-color --quiet --vus 100 --duration 1m load-test.js 2>&1 | Tee-Object results/run-100vu.txt
k6 run --no-color --quiet -e MODE=staged load-test.js 2>&1 | Tee-Object results/staged.txt
k6 run --no-color --quiet --vus 30 --duration 1m -e P95_LIMIT_MS=168 load-test.js 2>&1 | Tee-Object results/threshold-pass.txt
k6 run --no-color --quiet --vus 30 --duration 1m -e P95_LIMIT_MS=50 load-test.js 2>&1 | Tee-Object results/threshold-fail.txt
```

## Шаталсан ачаалал ба SLO

Шаталсан туршилтаар 30 секундэд 5 VU, дараагийн нэг минутад 30 VU, дараагийн 30 секундэд 100 VU хүргэж, сүүлийн 30 секундэд 0 VU хүртэл буулгав. Шаталсан туршилтаар нийт 4162 хүсэлт гүйцэтгэж, дунджаар секундэд 27.684176 хүсэлт боловсруулав. Нэгтгэсэн p95 нь 109.49 мс, алдааны хувь 0.00% байв. [Бүтэн гаралт](results/staged.txt).

5 VU-ийн суурь p95 хэмжилт ойролцоогоор 111.64 мс байв. Суурь утгыг 1.5-аар үржүүлж дээш бүхэлчилснээр p95-ийн дээд хязгаарыг 168 мс гэж тогтоов. Энэ нь суурь хэмжилтээс ойролцоогоор 50% өсөх зай өгнө. Хүсэлтийн алдааны хязгаар 1%. Ижил 30 VU ачаалалд 168 мс-ийн [PASS](results/threshold-pass.txt) болон 50 мс-ийн [FAIL](results/threshold-fail.txt) туршилтыг ажиллуулав.

## Дүгнэлт

5 VU үед секундэд 4.52 орчим хүсэлт гүйцэтгэсэн. Ачааллыг 30 VU болгоход энэ үзүүлэлт 27.10, 100 VU болгоход 90.33 болсон. Иймээс энэ туршилтын хүрээнд throughput хэрэглэгчийн тоотой бараг ижил харьцаагаар өссөн. p95 нь гурван хэмжилтэд 111.63–112.62 мс орчим байв. 30 VU үед p95 бага зэрэг өссөн ч 100 VU үед буцаад багассан тул хэрэглэгчийн туршлага тогтвортой муудсан цэг ажиглагдсангүй. Тогтмол ачааллын гурван туршилтад HTTP хүсэлт алдаагүй байв. Энэ нь хүсэлтийн хурд, хариу өгөх хугацаа, алдааны хувийг тус тусад нь хэмжих хэрэгтэйг харуулсан. Суурь хэмжилтээс гаргасан 168 мс-ийн SLO шалгалт 30 VU үед амжилттай болсон. Хязгаарыг 50 мс болгоход серверийн төлөвийн шалгалтууд амжилттай байсан ч k6 хугацааны шалгуурыг унагасан.
